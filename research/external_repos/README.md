截至 2026-08-13，本地已确认存在：

- `GRA/`
- `FreqFusion/`，含 `README.md` 和 `FreqFusion.py`
- `FDConv/`
- `GauCho/`
- `Strip-R-CNN/`
- `yolov10/`
- `LSKNet/`

`CANConv/` 尚未准备成功，目前是低优先级备选；直接 `SGC+FDF` 筛选已经完成且未通过，后续如换新 D 再单独评估是否需要补齐。

材料状态、目标目录和缺失项统一维护在 [DOWNLOAD_STATUS.md](DOWNLOAD_STATUS.md)，不要在本文件重复维护另一份下载清单。

若后续迁移第三方方法，应同时记录：论文与仓库链接、许可证、实际借鉴范围、与官方实现的差异、插入位置，以及对应训练配置和评估记录。
